# Python Certification — freeCodeCamp

A collection of Python exercises, algorithms, and programming projects completed while working through the **freeCodeCamp Python curriculum**.

This repository documents my progress building a foundation in Python programming, problem solving, data structures, algorithms, object-oriented programming, and error handling. Each folder contains practice files and exercises focused on a specific topic.

## Topics Covered

| Folder | Focus |
|---|---|
| `PythonBasics` | Python fundamentals, variables, data types, input/output, conditional statements, and basic validation programs |
| `Loop&Sequences` | `for` and `while` loops, iteration, strings, lists, tuples, sets, and dictionaries |
| `Classes&Objects` | Creating classes, objects, constructors, instance attributes, and methods |
| `ObjectOrientedProgramming` | Core OOP principles, including encapsulation, inheritance, polymorphism, and reusable class design |
| `ErrorHandling` | Handling exceptions with `try`, `except`, `else`, and `finally` blocks |
| `LinearDataStructures` | Fundamental linear data structures such as lists, stacks, queues, and linked lists |
| `Algorithms` | Problem-solving techniques and algorithm implementations |
| `Recursion` | Recursive functions, base cases, and recursive problem-solving approaches |
| `DynamicProgramming` | Optimization problems, memoization, tabulation, and sequence-based challenges |
| `Graphs&Trees` | Graph and tree traversal concepts, including breadth-first search and related algorithmic problems |
| `Certification_Projects` | Larger programming exercises and certification-related projects completed throughout the course |

## Skills Demonstrated

- Writing clean and readable Python code
